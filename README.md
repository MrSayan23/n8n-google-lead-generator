# n8n Google Lead Generator

Automated lead generation workflow built with n8n.

## Features

- Search businesses using Google Places API
- Extract business information
- Collect website URLs
- Extract email addresses from websites
- Save lead data automatically

## Workflow File

- Google_Lead.json

## Tech Stack

- n8n
- Google Places API
- Google Vertex AI
- Google Sheets

## How to Use

1. Import Google_Lead.json into n8n.
2. Configure Google Places API credentials.
3. Configure Google Vertex AI credentials.
4. Configure Google Sheets credentials.
5. Activate workflow.
